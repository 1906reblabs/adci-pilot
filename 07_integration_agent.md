# Agent 07 — Integration Agent

**Input:** `evidence/2026/<week>/observations.json` with pillar
commentary attached.

**Task:** ask whether these systems are becoming interconnected within a
country — not whether each is independently strong. Example chain worth
watching: digital ID → digital payments → fintech → stablecoins →
cross-border payments. Note where this week's evidence shows a link
strengthening, weakening, or newly appearing between two pillars.

**You do not change any value.** This is annotation only.

**Output** — append to `evidence/2026/<week>/integration_notes.md`, one
short entry per country, e.g.:

```
## Nigeria
CBN's [digital ID initiative] appears to be feeding directly into
[fintech KYC simplification] this quarter — GOV-01 and FIN-01 evidence
both cite the same underlying rollout. Watch for this to show up in
FIN-01 next quarter if adoption follows.
```
