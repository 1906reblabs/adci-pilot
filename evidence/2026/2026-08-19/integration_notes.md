# Integration Notes — Week of 2026-08-19

## South Africa
GOV-01 evidence (Smart ID migration) and Finance-pillar infrastructure are
visibly converging: Home Affairs' Smart ID rollout is now distributed
substantially *through retail banks* — FNB, Capitec, and Standard Bank
branches are issuing and reissuing Smart IDs directly, with over 300
partner branches live and a target of 750 by end of 2026
(sources: ZAF-GOV-01-01, ZAF-GOV-01-02). This is a concrete GOV↔FIN
integration point: banks are becoming a primary distribution channel for
a state identity credential, which is the reverse direction of the
"digital ID → KYC simplification" chain described in this project's
README example, but the same underlying pattern — government and
financial-sector infrastructure sharing rails. Watch for this to show up
as faster Smart ID adoption in areas with strong bank branch density, or
conversely for it to stall if banks deprioritize the low-margin service.

## Nigeria
Two pillars this week both point to the same likely root cause pulling
in opposite directions: FIN-02 evidence shows Nigeria's stablecoin/crypto
adoption at a global #2 ranking, explicitly attributed by multiple
sources to naira depreciation pushing citizens toward USDT as a savings
vehicle (source: NGA-FIN-02-01 and related search context). Meanwhile
ECO-02 evidence shows Nigeria was the only one of the three pilot
countries where tech VC+debt capital raised *declined* year-on-year in
2025 (-3%) even as the continental total rebounded +25% (source:
NGA-ECO-02-01). Currency instability plausibly explains both: it drives
retail crypto adoption up while depressing dollar-denominated investor
reporting. If the naira stabilizes, watch for FIN-02 growth to moderate
and ECO-02 to recover in the same cycle — a joint move would support the
shared-cause read; a divergence would suggest they're actually unrelated
and this pairing was coincidental.

## Kenya
The GOV-01→FIN interoperability chain described in this project's README
(digital ID → digital payments → fintech) does not yet show up in
Kenya's evidence the way it appears to be emerging in South Africa's.
Maisha Namba, Kenya's digital-ID program, remains shadowed by the
2023-24 court injunction over a missing Data Protection Impact
Assessment (lifted August 2024, but rollout continues under public
scrutiny — see this week's Society note). Until that legal/institutional
friction resolves, it is hard to construct a validated GOV-01 coverage
figure at all (see: no GOV-01 observation cleared review for Kenya this
week), let alone trace a GOV→FIN link. By contrast, Kenya's FIN pillar
strength this week comes entirely from M-Pesa — a fintech-native rail
that predates and is largely independent of the state ID system. Worth
watching whether Maisha Namba's slower, more contested rollout ends up
mattering less for Kenya's digital economy than it would for a country
starting from weaker private fintech infrastructure.
